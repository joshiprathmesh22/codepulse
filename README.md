# CodePulse

CodePulse is a full-stack engineering intelligence platform that connects with GitHub and transforms repository activity into actionable engineering insights.

It helps development teams monitor repositories, commits, pull requests, issues, branches, contributors, and overall repository health through a centralized analytics dashboard.

## 🚀 Key Features

- JWT-based authentication
- Email verification
- GitHub OAuth 2.0 integration
- GitHub repository synchronization
- Repository management
- Commit tracking
- Pull request tracking
- Issue tracking
- Branch tracking
- Contributor analytics
- Repository health metrics
- Engineering activity dashboard
- Role-based access control
- RESTful APIs with Django REST Framework

## 🎯 Goal

CodePulse is designed to turn raw GitHub activity into meaningful engineering insights, helping teams understand development activity, repository health, collaboration, and productivity from a single dashboard.
